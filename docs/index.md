# Mason

Mason (the `mason` command) is a terminal tool, TUI and web app for looking after many GitHub and
GitLab repositories at once: status, pull requests, merges, workflow runs and approvals, security
alerts, stats, and drift checks against shared defaults.

The [README](https://github.com/bitsandbricks-ch/mason-cli#readme) covers installing and the
commands. These pages go further:

- [Mason web app](mason.md): running it, signing in, operators, settings and the security model
- [Repo settings](settings.md): every GitHub and GitLab repo setting Mason knows
- [Threat model](threat-model.md): what Mason protects, where it can be reached, and how
- [Backlog](BACKLOG.md)
